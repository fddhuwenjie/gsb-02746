# RCQ读者书库

一个用于抓取、管理和阅读期刊文章的全栈应用系统。

## How to Run

```bash
# 克隆项目后，在项目根目录执行
docker-compose up --build -d

# 查看服务状态
docker-compose ps

# 停止服务
docker-compose down
```

### 快速测试步骤

1. 启动服务后，访问 http://localhost:3001
2. 点击导航栏「抓取」进入抓取页面
3. 点击「一键模拟抓取」按钮添加模拟数据
4. 返回首页查看文章列表
5. 点击任意文章查看详情

### API 测试

```bash
# 获取文章列表
curl http://localhost:9000/api/articles

# 按条件筛选文章
curl "http://localhost:9000/api/articles?year=2024&month=1"

# 搜索文章
curl "http://localhost:9000/api/articles?search=人生"

# 获取单篇文章
curl http://localhost:9000/api/articles/1

# 获取所有期数
curl http://localhost:9000/api/articles/issues

# 获取所有分类
curl http://localhost:9000/api/articles/categories

# 添加测试数据
curl -X POST http://localhost:9000/api/articles/seed

# 模拟抓取（无需配置数据源）
curl -X POST http://localhost:9000/api/crawler/mock

# 启动抓取任务
curl -X POST http://localhost:9000/api/crawler/start \
  -H "Content-Type: application/json" \
  -d '{"year": 2024, "month": 5}'

# 查询抓取状态
curl http://localhost:9000/api/crawler/status

# 获取数据源配置
curl http://localhost:9000/api/crawler/sources

# 获取设置
curl http://localhost:9000/api/settings

# 更新设置（持久化保存）
curl -X PUT http://localhost:9000/api/settings \
  -H "Content-Type: application/json" \
  -d '{"articles_path": "./data/my_articles"}'

# 添加模拟数据源
curl -X POST http://localhost:9000/api/settings/sources/mock
```

## 题目内容

我需要设计一个读者书库项目，名称命名为"RCQ读者书库"，需要寻找一个适合爬取的期刊网站，并且满足以下的功能，如果你找不到适合的网站，请告诉我说"提供网站地址"，其中的功能要求如下：

1. 指定抓取数据的期数
2. 指定文章保存的路径
3. 抓取指定月份的所有读者文章，并保存
4. 可以以不同的形式显示文章列表
5. 可以在软件中打开选中的文章
6. 良好的人机交互界面

以此为要求，设计一个python程序

**重要说明**：经过搜索，未能找到公开可爬取的"读者"杂志官方网站。大多数期刊内容都在付费平台或移动App上，不提供公开的网页版本。

### 测试人员须知

由于未找到合适的公开数据源，系统提供了以下测试方式：

#### 方式一：一键模拟抓取（推荐）

1. 访问 http://localhost:3001/crawler
2. 点击「一键模拟抓取」按钮
3. 系统会自动添加模拟文章数据
4. 返回首页即可查看和测试所有功能

#### 方式二：添加测试数据

1. 访问 http://localhost:3001/crawler
2. 点击「添加测试数据」按钮
3. 系统会添加 8 篇预设的测试文章

#### 方式三：配置真实数据源

如果您有可用的期刊网站，可以按以下步骤配置：

**通过界面配置**

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 访问 http://localhost:3001/settings | 打开设置页面 |
| 2 | 填写「数据源名称」 | 如：读者在线、散文网等 |
| 3 | 填写「基础URL」 | 网站根地址，如 `https://example.com` |
| 4 | 填写「列表页URL模式」 | 如 `/archive/{year}/{month}`，支持变量替换 |
| 5 | 填写「文章链接选择器」 | 用于定位文章链接的CSS选择器 |
| 6 | 填写「标题选择器」 | 用于提取文章标题的CSS选择器 |
| 7 | 填写「内容选择器」 | 用于提取文章正文的CSS选择器 |
| 8 | 填写「作者选择器」（可选） | 用于提取作者的CSS选择器 |
| 9 | 填写「分类选择器」（可选） | 用于提取分类的CSS选择器 |
| 10 | 点击「添加数据源」 | 保存配置 |

**直接编辑配置文件**

编辑 `backend/config/sources.json` 文件：

```json
{
  "sources": [
    {
      "name": "您找到的期刊网站名称",
      "base_url": "https://您找到的网站地址",
      "list_pattern": "/文章列表页路径/{year}/{month}",
      "article_selector": "文章链接的CSS选择器",
      "title_selector": "标题的CSS选择器",
      "content_selector": "正文的CSS选择器",
      "author_selector": "作者的CSS选择器",
      "category_selector": "分类的CSS选择器"
    }
  ]
}
```

#### CSS选择器获取方法

1. 打开目标网站，按 F12 打开开发者工具
2. 使用「元素选择器」工具点击目标元素
3. 右键点击元素 → 复制 → 复制选择器
4. 将复制的选择器填入对应配置项

## 项目介绍

RCQ读者书库是一个全栈期刊文章管理系统，支持从配置的数据源抓取文章内容，提供优雅的阅读体验。

### 技术栈

- **后端**: Python FastAPI + SQLite + BeautifulSoup4
- **前端**: Vue 3 + Vite + TailwindCSS

### 功能特性

- 📚 按期数/月份抓取文章
- 📁 自定义文章保存路径（持久化）
- 📋 多种文章列表展示方式（列表/卡片/时间线）
- 📖 内置文章阅读器
- 🎨 现代化 UI 设计（Toast 提示、流畅动画）
- ✅ 输入校验（年份、月份、路径安全检查）
- 📝 日志记录（便于排障）
- 🧪 自动化测试覆盖
